# 1.0.3 - 未发布

## 播放体验

- 自动旋转改为仅在全屏中跟随实际视频方向：系列选片或列表循环切换到横向／竖向视频后，旋转到对应方向并保留全屏。普通播放不再因视频方向自动进入全屏；未知尺寸或正方形保持方向不变。“自动全屏”仍为独立设置。
- 从相关推荐打开视频时新建播放活动，返回可回到原播放页；系列选片、全屏播放清单和列表循环继续复用当前播放页。
- 竖屏普通播放器的中间三分之一区域新增下滑进入竖屏全屏；中间上划保持原有全屏行为。保留播放状态，短滑动、取消和多指介入不触发全屏，左右亮度／音量与横滑进度保持不变。
- 精简 README，保留下载、主要功能与用法、构建方式、安全提示及验证限制；同步简体中文、繁体中文和英文的手势及自动旋转说明。
- 播放器齿轮设置改为从右侧滑入的不透明面板；竖屏普通播放时贴合简介／评论内容区，保留上方视频可见。播放模式和比例改为点开后选择，不再使用长按拖动切换。
- 横屏播放清单新增“展开／收起”：展开后与原播放画面并排显示，收起或返回恢复完整画面；不重启媒体，继续支持正序／倒序、当前项定位和系列内选片。
