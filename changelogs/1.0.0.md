# 1.0.0 - 2026-11-25

## 新增

- 本地收藏与本地待播放列表，无需登录，重启应用后仍然保留，与网站账号的在线列表相互独立。
- 视频简介页可加入或移出本地列表；侧边栏可查看列表，点击播放、长按移除，并支持清空当前列表。
- 本地收藏按最新加入优先排列；待播放按加入顺序排列，打开视频后不会自动移除，也不会自动下载视频。
- 播放器中间三分之一区域上划、松手进入全屏，保留进度及播放或暂停状态，支持返回普通窗口。
- 新增功能提供简体中文、繁体中文和英文界面文案。

## 修复与优化

- 修复未配置 GitHub Token 时检查更新返回 HTTP 401 的问题；Token 失效时会尝试匿名检查公开版本。
- 移除 GitHub 固定 IP，改用系统 DNS；恢复“已是最新版”和多次失败后的手动重新检查。
- 更新检测兼容新的语义化版本标签与旧版带构建号的标签，避免对同一正式版本反复提示更新。
- 全屏上划手势排除短滑、下滑、多指、取消和明显斜向操作，保留横划进度、两侧亮度和音量、双击及长按倍速手势。
- 触摸取消时恢复长按倍速前的播放速度，避免临时倍速残留。
- 补充本地列表的去重、排序、隔离和持久化测试，以及更新认证、版本比较和播放器手势回归测试。

## 隐私

- 移除使用情况统计、页面和搜索埋点、性能监控及自动崩溃上报，包括对应 SDK、设置项和文案。
- Firebase 仅保留更新渠道所用的 Remote Config；本地列表不会同步到网站。

## 安装说明

- Release APK 沿用本分支的公开测试签名，可用于社区测试，不适用于正式商店分发。
- 与原版或其他签名的安装包不兼容时，不要直接卸载以免丢失数据；请先备份并确认签名来源。
- 列表保存的是视频信息，未下载的视频播放仍需要网络；清除应用数据或卸载应用会移除本地列表。
- 登录后的在线列表、订阅、评论与点赞等交互尚未完成完整线上验收。
