# 1.0.1 - 未发布

## 新增

- 新增“备份与隐私”设置，支持本地文件和 WebDAV 分项备份 / 恢复观看历史、搜索历史、应用设置、本地收藏与本地待播放；恢复前校验并显示数量，经确认后合并去重，不清空已有数据或修改未选类别。
- 应用设置使用可移植白名单，同名设置覆盖、屏蔽规则合并，不导出登录凭据、WebDAV 配置和下载文件 / 路径。备份为未加密的版本化 JSON，限制 20 MiB / 100,000 项；WebDAV 采用完整 HTTPS 文件地址和独立 PUT / GET 客户端，上传前确认覆盖，账号密码在本机加密并排除系统备份，不跟随重定向或绕过证书校验。
- 新增持久化隐私模式，停止新增搜索与观看历史，拦截跨越开关切换的延迟写入；保留旧历史，不影响手动收藏、待播放、下载和显式备份恢复，也不改变现有搜索与标签补全。
- 统一视频卡片长按菜单，提供复制、本地“稍候再看”、当前视频标签 / 作者屏蔽及屏蔽设置入口，保留历史、本地 / 在线列表原有删除确认；补齐简繁英文案，以及备份校验、WebDAV 配置、隐私并发和数据库合并回归用例（尚未运行）。
- 首页右上角搜索入口改为独立搜索历史页，与侧边栏入口统一；新增搜索框、按钮与键盘提交、即时历史筛选及简繁英离线标签补全，保留多标签与标题混合搜索、最近优先、点击重搜、删除单条和确认清空。
- 移除原搜索结果页的历史下拉、历史按钮、展开动画与相关监听/专用接口；继续复用本地历史数据和统一记录流程，保留结果页、高级搜索及标签/作者/分类直达结果路径。
- 搜索支持空格分隔多个标签并混合标题关键词，识别简繁英完整标签名称、显式 # 标签及带引号的标题，与高级搜索标签合并；补齐三语提示与帮助。
- 更新弹窗支持 Markdown 更新说明，包括标题、强调、删除线、引用、列表、任务列表、代码、表格及网页链接，保留文本换行与滚动；使用原生主题文本渲染，不加载远程图片或执行 HTML/脚本。
- 设置的“更新”分类新增“禁用自动更新”开关，默认关闭；开启后停止自动检查与更新弹窗，保留手动检查及更新渠道选择，重启后仍生效。
- 本地标签/作者屏蔽规则，支持设置页添加、去重与解除，重启后保留，无需登录。
- 视频简介页与长按菜单提供快捷屏蔽入口，保留原有复制功能。
- 首页（含视频横幅）、搜索及相关推荐按完整标签/作者名称过滤，不修改已有收藏、待播放、历史、系列列表和下载。
- 缺失资料按需限并发查询并缓存；无法确认的卡片暂不展示，可刷新重试；整页过滤后仍可继续加载搜索结果。
- 补充简体中文、繁体中文、英文文案、规则和过滤测试、持久化及界面回归测试。

## 修复

- 修复播放页点击标签搜索绕过搜索历史写入的问题；观看历史改在详情交互前保存，本地事务不随页面离开而取消，避免跳转搜索时漏记，不影响离线下载播放。
- 屏蔽图标改为跟随主题颜色，修复深色模式下黑色图标不清晰的问题，覆盖设置入口、规则添加项与视频详情按钮。
- 修复视频详情页作者头像误读默认占位图的问题，优先读取叠放的真实头像，兼容旧版结构并保留默认头像回退。
